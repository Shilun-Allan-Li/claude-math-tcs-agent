Core principle

The engineer layer is request-response only.

It receives a bounded tool request and returns a compact audited report.

It supports:
- local/source search
- Python experiments
- token counting
- source indexing
- compact result auditing

It does not decide:
	•	proof strategy
	•	whether a theorem is true
	•	whether a distilled pattern should be promoted
	•	whether a generated skill is conceptually correct
	•	what the final proof should say
